# 01_项目网络拓扑

本图依据用户提供的“项目网络.jpg”草图转换，保留原图的网络名称、设备数量、区域边界与连接箭头。江北大数据局的政务外网通过图中标注的政务外网IP，连接街道机房的防火墙/路由器；该设备标注了一对一NAT，再连接交换机和VPN专网。

SIP中继服务器位于街道机房内，原图左侧线路连接交换机，右侧线路连接软交换网络。机房内还有硬盘录像机，经互联网专线连接视联平台，再连接一网统管平台。VPN专网向下连接分支点，分支点包括原图标注的“8个卡口监控、36个摄像头”和“消控室36台传输装置”。

红色手写标记“1”和“2”已保留，原图未说明其含义，需向现场人员确认。原图箭头仅按可见方向复现，不能据此确定业务请求方向、双向可达性、协议或防火墙放行策略。

原图没有给出IP地址、子网掩码、网关、VLAN、端口和具体NAT映射，也没有标明拟部署的若依应用服务器位置。这些信息均需现场补充；本图没有将部署建议加入现状网络。原图的编辑器选择手柄不属于网络设备，未作为节点保留。

设备图标来自原图的独立裁剪，文字、区域、蓝色网络云和线路以可编辑原生对象恢复。后续移动节点时，应核对并按需调整线路端点，不能假设线路会自动跟随重连。
