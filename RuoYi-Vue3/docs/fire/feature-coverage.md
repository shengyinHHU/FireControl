# 功能清单覆盖与接入边界

依据原Excel《软件功能清单》行号，不以不连续序号猜测缺失需求。所有消防业务已提供前端入口及模拟流程，真实外部平台接入单独说明。

|9|网格下钻|grids / dashboard|按gridId过滤所属场所并查看档案|
|10|分类图层与打点|dashboard|四类场所、警情、POI、网格等显隐|
